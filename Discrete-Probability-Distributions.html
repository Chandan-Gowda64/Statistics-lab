Binomial Distribution

The number of successes X in n independent trials, where every trial succeeds with the same probability p.

Exercise 1 – Interactive Binomial Distribution UI

Use the Binomial Distribution module developed in the lab application.

Configure the application with:

  • Number of trials: n = 15
  • Probability of success: p = 0.6

Using the UI, determine:

  1. Mean and variance of the distribution.
  2. P(X=9) — probability of exactly 9 successes.
  3. P(X ≤ 10) — probability of at most 10 successes.
  4. Observe the PMF graph and identify the region where the probability is highest.
  5. Write a brief inference from the visualization.

Inputs

Positive whole number, up to 1000.

Between 0 and 1.

Probability mass function

P(X=k) = C(n,k) pk (1−p)n−k

Cumulative distribution function

P(X ≤ k) means the probability of getting k or fewer successes.

PMF graph

  • P(X = x)
  • Mean

Poisson Distribution

The number of events X in a fixed interval when events occur independently at an average rate λ.

Exercise 2 – Interactive Poisson Distribution UI

Use the Poisson Distribution module developed in the lab application.

Consider an AI-based monitoring system where the average number of events is λ = 6.

Using the UI, determine:

  1. Mean and variance of the distribution.
  2. P(X=8) — probability of exactly 8 events.
  3. P(X ≤ 5) — probability of at most 5 events.
  4. Compare the Poisson PMF graphs for λ = 2, 6 and 10 using the application.
  5. Observe how increasing λ changes the distribution and write a brief inference from the graph.

Inputs

Positive number, up to 100.

Probability mass function

P(X=k) = e−λ λk / k!

Cumulative distribution function

P(X ≤ k) means the probability of getting k or fewer events.

PMF graph

  • P(X = x)
  • Mean

Compare PMFs for λ = 2, 6 and 10

  • λ = 2
  • λ = 6
  • λ = 10

Hover or touch the graph to compare the three values at each X.
